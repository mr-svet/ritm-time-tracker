# Светлая палитра, сводка и упрощение страниц — 29.10.2026

Статус: локальные изменения поверх16bc824, НЕ ПРОВЕРЕНЫ и НЕ ОПУБЛИКОВАНЫ. Автономный HTML не пересобран. Один агент, без делегирования.

## Изменения по запросу

1. Светлая палитра: сине-серые ползунки/полосы прокрутки, приглушённые бирюзовые/синие графики, более заметные овалы анимации, синяя движущаяся точка вместо жёлтой. Представление цветов категорий меняется только в интерфейсе, сохранённые цвета в данных не переписываются. SVG-иллюстрации сцен перекрашены как исходный векторный код в холодные оттенки; фотографические JPG/PNG не менялись. Тёмная палитра основных графиков не менялась; SVG используются также как краткая подложка тёмной сцены при загрузке фотографии.
2. Для посетителя эффективная сцена всегда mountains при светлой теме, forest при тёмной. Выбор владельца берётся из прежних предпочтений отдельно. Для посетителя кнопка выбора картины скрыта, чтобы не предлагать действие, которое не изменяет закреплённую сцену. Привязка гостя задаётся при visitor-входе и при восстановлении гостевой сессии.
3. Подпись ночного сна выровнена влево, числовые значения остаются центрированными.
4. Подъём/отбой/ночной сон помещены в группу «Сон и пробуждение», закрытую при начальном открытии. Переключатель сохраняет состояние на время текущей страницы, строки скрываются отдельным tbody с hidden и aria-controls. Данные не меняются.
5. Существующий разворот, ранее скрытый на desktop, доступен на всех ширинах. Таблица занимает доступную область окна (CSS overlay, не системный fullscreen браузера), фон/навигация скрываются, таблица прокручивается внутри. Выход кнопкой или Escape, клавиатурный фокус ограничен элементами развёрнутой таблицы; открытый редактор-dialog сохраняет собственное управление.
6. См. диагностику ниже. Над журналом добавлены общая длительность завершённых пропусков и первые три интервала. При текстовом поиске показано пояснение, что для пропусков нужно очистить поиск. Строки пропусков по-прежнему вычисляемые.
7. Убраны select категории и проекта на /journal. Их скрытая фильтрация тоже не применяется: журнал использует даты и текстовый поиск. Переход из деталей сводки открывает весь выбранный день, очищая старые фильтры/поиск. Категории и проекты самих записей, формы записи и настройки не удаляются. Кнопка «Открыть деморежим» убрана только из шапки.
8. На /stats убран верхний блок четырёх metric-карточек; графики и аналитика ниже сохранены. Аналогичные карточки главной страницы не убирались.

## Диагностика 95% и журнала до правок

По прямому запросу владельца на рабочей версии16bc824 выполнено readOnly-чтение числовых данных 28октября без текстов занятий. Сводка:840минут из880,40минут пропуска,95%. journalTimeline без поиска/фильтров формирует17строк (15реальных и2пропуска), меньше лимита50. Интервалы пропусков:22:56–23:26 и23:26–23:36.

Отсутствие строк на конкретном пользовательском экране не воспроизведено и не объявляется доказанно объяснённым. Статически установлено, что прежние фильтры категории/проекта и поиск отключали маркеры, хотя процент продолжал считаться по полному дню. Новая версия исключает скрытую фильтрацию категорией/проектом и явно показывает сумму/примеры пропусков. Для подтверждения нужен будущий разрешённый прогон интерфейса.

Личные записи, время подъёма/отбоя, категории и проекты на сервере не менялись.
